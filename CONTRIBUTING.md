# Contributing to EU & Nordic Official Open-Data MCP Suite

Contributions are welcome! Before opening an issue or pull request, please verify:

1. **Clean Open-Data Licensing:** Every upstream dataset must permit commercial reuse (CC BY 4.0 or EU Commission Decision 2011/833/EU) and be documented in `licences.json` and `LICENCE_REGISTER.md`.
2. **Embedded Attribution:** Every record and MCP response (including error responses) must include the source's required attribution string.
3. **GDPR Compliance:** Strip natural-person names, personal emails, and residential addresses from all responses.
4. **No Official Logos:** Never use PRH, Fingrid, FMI, TED, ECB, VIES, ENISA, Digitraffic, or EU logos.
